# Tegia Legal — Centro de comandos

Repositorio privado del proyecto de Tegia Legal: email marketing con SendGrid, sitio web seguro, CRM, tableros y automatizaciones.

- `.claude/skills/tegia-legal/` — skill con el contexto, las reglas y el estado del proyecto. Claude Code la carga automáticamente en cada sesión con este repositorio y la mantiene actualizada.

Nunca guardes claves, contraseñas ni datos de clientes en este repositorio.
